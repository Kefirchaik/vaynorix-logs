# VAYNORIX RP Logs — Release 1.3.0

- Новый главный раздел «Обзор сервера» (сразу после входа).
- Количество аккаунтов, онлайн по состоянию `accounts.online=1`, общий запас денег и 6-частная детализация.
- Адаптивные карточки для телефона, планшета, ПК. Кнопка обновления и автообновление каждую минуту.
- Тільки читання гральних таблиць; немає нових таблиць, парольних змін чи змін у гральному моді.
- Важливо: онлайн може бути застарілим після аварійного перезапуску сервера.
- Гроші в `money_log` НЕ додаються до залишків, щоб уникнути подвійного підрахунку.
- Server-side кэш 30 секунд.
