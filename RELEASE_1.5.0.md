# VAYNORIX RP Logs — Operations Console 1.5.0

## Что изменено

- Полностью обновлённый интерфейс: компактная панель, глубокая тёмная палитра с бирюзовыми акцентами, читаемая светлая тема.
- Верхние вкладки «Обзор / Проверки / Журналы / Игроки / Семьи» и прежнее боковое меню для всех разделов.
- Быстрый поиск игрока по нику или ID (на ПК клавиша `/`; на телефоне через вкладку «Игроки»).
- Фильтры, таблицы и карточки, адаптированные под телефон, планшет и ПК.
- Суммы в денежных журналах подсвечиваются по знаку; крупные операции сохраняют прежнюю отметку для ручной проверки.
- На вкладке «Проверки» после загрузки анализа появляется счётчик приоритетных сигналов.
- Совместимость с существующей авторизацией Owner + 2 Admin и одной MariaDB.

## Ограничения

Сайт остаётся инструментом просмотра: игровые операции выполняют только `SELECT`, а аккаунты администраторов — прежние служебные таблицы. Никаких новых SQL-полей, Redis, новых пользователей MySQL или дополнительных переменных Vercel не требуется.

Скриншоты другого проекта использовались как референс компоновки, не как источник структуры БД. У VAYNORIX в представленном дампе нет подтверждённого журнала входов `login_log`, поэтому точные длительности сессий, баланс до/после и доказанную связь перевода с получателем сайт не выдумывает. Совпадение IP остаётся поводом для проверки, а не доказательством мультиаккаунта.

## Проверка

- Браузерный макет с имитацией API проверен на ширинах 320, 390, 768 и 1440 px: переполнения страницы нет, ошибок JavaScript нет.
- Полноценные запросы к игровой БД и рабочий Vercel-деплой необходимо проверить после публикации.

## Развёртывание

Репозиторий: https://github.com/Kefirchaik/vaynorix-logs

Vercel → проект `vaynorix-logs` → **Deployments**. При включённом авто-деплое с GitHub обновление появится после коммита. Иначе выполни **Redeploy** последнего коммита.

Сохрани предыдущий деплой как точку отката. Настройки `DB_*`, `SESSION_SECRET` остаются без изменений.
